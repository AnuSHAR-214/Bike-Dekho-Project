# Bike-Dekho-Project
1. Analysed BikeDekho sales data using Excel to identify customer purchasing trends and sales performance. 
2. Cleaned and organised data, created PivotTables and Pivot Charts, and used functions such as IF, SUMIFS, and COUNTIFS to generate insights. 
3. Developed an interactive dashboard with KPIs and slicers for easy data visualisation and decision-making.
